# Tinyvation deployment is configured via GitHub Actions

If you are seeing this page, GitHub Pages is currently set to **Deploy from a branch**.

To publish the full Next.js site:

1. Go to **Settings → Pages**
2. Under **Build and deployment → Source**, choose **GitHub Actions**
3. Re-run the workflow: **Deploy static Next.js site to GitHub Pages**

After that, this branch-based Jekyll page is no longer used.
