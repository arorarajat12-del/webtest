GitHub Pages setup

Tinyvation is configured for the Actions deploy workflow.

If you are seeing this fallback page, the repository is still set to Deploy from a branch. The complete Tinyvation website is a Next.js static export that should be deployed by the repository workflow instead.

  1. Open Settings → Pages in the GitHub repository.
  2. Under Build and deployment → Source, choose GitHub Actions.
  3. Run Deploy static Next.js site to GitHub Pages from the Actions tab.

This static fallback also prevents GitHub’s legacy Jekyll builder from failing when the Pages source is temporarily pointed at the docs folder.
